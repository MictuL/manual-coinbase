# Manual Coinbase · Clientes de Axen Broker

Manual interactivo paso a paso para que los clientes de Axen Broker **en Estados Unidos** usen Coinbase:
6 guías (abrir cuenta, depositar y comprar USDT, fondear Axen Broker por la red Ethereum (ERC-20), cobrar ganancias, pasar el dinero al banco y Coinbase Card), en celular o computadora, modo oscuro y claro.

Si el visitante elige «México», el manual le sugiere ir al **Manual Binance** (repositorio `manual-binance`).

- Sitio estático de un solo archivo: `index.html` (sin dependencias ni compilación).
- Parámetros opcionales: `?dispositivo=app|web` y `?tema=dark|light`.
- Despliegue: Vercel (Framework Preset: **Other**, sin comando de build, carpeta raíz `/`).
- `vercel.json` desactiva la caché agresiva para que cada push se vea de inmediato.

> Las pantallas de Coinbase son ilustraciones con datos ficticios. El contenido financiero requiere validación de Compliance y Legal antes de publicarse a clientes.
